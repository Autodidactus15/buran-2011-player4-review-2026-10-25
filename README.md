# Разбор игры №4 «Бурана»

Статическая страница с полным разбором матча «Буран» 2011 — СК «Брянск» 2011 от 25 октября 2026 года: 125 наблюдений, 9 видеопримеров и журнал 25 блоков выхода на лёд. Расчёт игрового времени ручной; ограничения и сценарии сохранены в тексте.

Клипы представлены в компактном размере для телефона и в полной версии для скачивания. Оригинальная полная запись матча в репозиторий не включена.

## Публикация

GitHub Pages публикует корень ветки `main`. Сборка и установка зависимостей не нужны. После изменения файлов на этом компьютере выполните из этой папки:

```powershell
git add .
git commit -m "Update hockey review"
git push
```

Главные файлы: `index.html`, `styles.css`, `app.js`, `data.json`. В `assets` находятся клипы, кадры и выгрузки данных. Страница использует относительные ссылки и подходит для публикации в подпапке GitHub Pages.

Оценка относится к одному матчу. Таймкоды соответствуют предоставленной записи; паузы и повторы не считаются игровым временем.
